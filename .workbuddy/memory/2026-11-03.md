## 紧急修复：context.py 类体被提前关闭（本次）
- 症状：运行时 `AttributeError: 'GameCtx' object has no attribute 'anick'` / `'refresh_card'`，Docker 部署后所有指令（如 #resume）报错。
- 根因：上一轮把 `_at_id`/`_at_name` 改成 0 缩进的模块级函数并放在 `log_error` 之后，导致 `GameCtx` 类在 L67 处提前关闭，`anick`/`refresh_card`/`ats`/`nums`…`_store_card` 共 15 个本应属于类的方法被 `_at_name` 吞成其内部嵌套死代码（写在 return 之后）。
- 修复：删除中间那段模块级函数（L67–L89），把它们原样追加到文件末尾（模块级）；`GameCtx` 重新吸纳 21 个方法；调用点 `_at_id(...)`/`_at_name(...)` 保持模块级调用无需改动。
- 验证：`ast.parse` 确认 GameCtx 含 21 方法，`compileall` 全包通过。
- ⚠️ 教训：把函数改成模块级时，绝不能插在类体中间（会提前关闭类）；应放文件末尾，或保留为类内 `@staticmethod`。
